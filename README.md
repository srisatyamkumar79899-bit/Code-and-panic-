
# SIH Skill Intelligence & Learning Platform — Frontend

Static frontend demo built from the supplied project description and website requirements.

## Included flows
- Login with password / OTP-style screen
- Employee registration with Centre/State, department, organisation, designation, email, experience
- Role-based default competency profile
- Role-based future skill requirements
- Initial/default recommended courses
- Competency assessment
- Skill-gap analysis
- Personalized recommendations after assessment
- Learning/progress pages
- Interactive employee profile/dashboard
- Admin dashboard demo
- iGOT / NSSTA-TPAC catalogue placeholder area

## Run
Just open `index.html` in a browser.

The site is frontend-only. Login, assessment results, course data and admin analytics are mock/demo data and are not connected to a backend or live iGOT API.
